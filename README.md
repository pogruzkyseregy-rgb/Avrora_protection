# AvrorA Protection

Приложение для Android, которое проверяет APK-файл **до установки**.
Файл никуда не отправляется: всё считается прямо на телефоне.

## Что проверяется

- **Опасные разрешения.** Что приложение просит: SMS, камеру, микрофон, контакты, доступ ко всем файлам и т. п. Для каждого есть объяснение простыми словами.
- **Подпись.** Есть ли у файла подпись сертификатом. Нет подписи, значит непонятно, кто его создал.
- **SHA-256.** Уникальный отпечаток файла. Его можно сравнить с тем, что опубликовал разработчик.
- **Название пакета и версия.**

## Что означает оценка

- **0–24, зелёный.** Опасных признаков мало.
- **25–59, жёлтый.** Есть вопросы. Прочитай пункты перед установкой.
- **60–100, красный.** Много опасных возможностей или нет подписи. Не ставь, пока не разберёшься.

Это оценка по разрешениям и подписи. Она **не** заменяет антивирус и **не** гарантирует безопасность.

## Как пользоваться

1. Открой приложение.
2. Нажми «Выбрать APK для проверки» и укажи файл.
3. Прочитай отчёт и решай сам.

## Статус

Ранняя версия (0.1.0). Пока есть:

- выбор файла через системное окно;
- разбор разрешений, подписи и хеша;
- экран отчёта в стиле Авроры.

В планах: открытие через «Поделиться» из файлового менеджера, проверка по VirusTotal, сравнение хеша с опубликованным.

## Сборка

Нужны Android Studio (Ladybug или новее) и JDK 17.

1. Открой папку проекта в Android Studio.
2. Дождись синхронизации Gradle.
3. Запусти на телефоне или эмуляторе с Android 9 (API 28) и новее.

Gradle wrapper в репозиторий пока не добавлен. Android Studio создаст его сам при первой синхронизации.
